# Privacy Policy — AI YouTube OS

Last updated: 2026-09-28

AI YouTube OS is a Claude Code plugin made of text instructions (commands, a skill, templates) and two local Python scripts.

- **We collect no data.** The plugin has no MCP server, no hooks, no analytics, and makes no network requests of its own.
- **Everything stays on your machine.** The scripts only run `ffmpeg`, `ffprobe`, and `python3` locally and only read or write files in the channel folder you point them at.
- **Third-party tools are yours.** Web search, voice or video generation, and YouTube uploads happen only through tools and accounts you connect yourself, under those services' own privacy policies.
